# Бот с QR и ссылками банков

Этот проект отдельный. Он не использует и не содержит API-ключей букмекеров.

Что делает бот:

- принимает игровой ID только как текст, без проверки через API;
- показывает единый статичный QR-код `assets/payment_qr.png`;
- создаёт сумму с уникальными тыйынами;
- показывает кнопки MBANK, O!Деньги, Bakai и MegaPay;
- после выбора банка открывает официальную страницу приложения для Android или iPhone;
- принимает чек и передаёт заявку администратору вручную.

Перед запуском в Railway добавьте только эти переменные:

```text
BOT_TOKEN=токен_нового_бота_из_BotFather
ADMIN_IDS=ваш_telegram_id
SUPPORT_USERNAME=@ваш_аккаунт_поддержки
PAYMENT_QR_IMAGE=assets/payment_qr.png
```

При необходимости замените `assets/payment_qr.png` на ваш QR-код. Не добавляйте `PAYMENT_QR_URL_TEMPLATE`: для статичного QR он не нужен.
